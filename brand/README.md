# Kit da marca WingsBr

Arquivos-mestre do Mini Brand Book v1.0 (Grifo Agency, out 2026), em SVG (vetor) e PNG.

| Pasta       | Conteúdo                                       |
| ----------- | ---------------------------------------------- |
| `logo/`     | Assinatura horizontal, variações 1 a 4         |
| `icon/`     | Símbolo isolado, variações 1 a 5               |
| `app-icon/` | Ícone de aplicativo, variações 1 a 5           |

Esta pasta não é publicada com o site. A logo usada na página vem do sprite em `src/components/brand/BrandSprite.astro`, que reproduz o mesmo desenho.

Não edite os arquivos: qualquer ajuste de marca passa pela aprovação do brand book.
